# Decisions log

## 2026-09-17 — Art direction (from the Cowork session)
- Rejected: glossy 3D "Pixar" pets (too mainstream), gummy/vinyl/chrome/voxel/clay/shadow directions, felt-on-low-poly.
- Chosen: cozy pixel art. Habitats on a 160×120 grid, pets as 80×80 sprite strips, 8 fps stepped motion, ambient FX at 60 fps.
- Gen 1 species: fish (bowl → tank), hamster (cage → terrarium), frog (pond → jar), chicken (brooder day 0–7 → coop).
- The habitat IS the widget: transparent frameless always-on-top window, resizable S/M/L, minimizes to a tray chip.
- The pantry (feeder object in each habitat) is the visible away-mode gauge. Feed = burn 25 $FEED. Decay 100/60h. Death after 24h at zero.
- Phase 0 local only; Phase 2 moves authority to Solana (Metaplex Core + Anchor feeder program + keeper crank).

## 2026-09-17 — Phase 0 scaffold and architecture contract
- Stack pinned: Tauri 2.11 (Tauri 3 is alpha on crates.io; not used), Vite 8.3, TypeScript 5.9 (TS 7 native port skipped for Vite/Vitest compatibility), Vitest 3.2, PixiJS 8.20, Zustand 5 (vanilla store, no React), Howler 2.2, Playwright 1.63.
- `docs/ARCHITECTURE.md` is the binding module contract so sim / shell / render / ui can be built in parallel. Dependency direction: sim ← app ← (render, ui) ← main; platform is only imported by app, ui, main.
- Added `lastReconciledAt` to `PetState` (not in the Blueprint). Reason: `reconcile()` must walk only forward from the last applied time so a pantry deposit made after a hunger crossing is not applied retroactively, and so reconcile is idempotent. Persisted with the pet.
- `Ledger` gained `debit(n)` / `credit(n)` next to `burn(n)` because pantry deposit/withdraw moves tokens rather than destroying them. Phase 2 maps them to `pantry_deposit` / `pantry_withdraw`.
- Auto-feed trigger is `hunger <= PANTRY_TRIGGER` (30), evaluated at the exact crossing timestamp. A fresh pet at 100 with 500 in the pantry gets 8 auto-feeds in 10 days (42 h, then every 27 h) and ends with 300 in the pantry; the Blueprint's "~250 or less" is only reached when the pet starts below full.
- Window padding: `WINDOW_PAD = 24` CSS px on every side (window = 160s+48 × 120s+48), read as "24 px padding for the HUD and shadow" per side so the hover pill fits above the bowl without covering it.
- Click-through: Rust polls the global cursor position and toggles `set_ignore_cursor_events` against hit regions the frontend sends, because a webview that ignores cursor events cannot see the cursor come back. Documented in the contract as the macOS workaround.
- Assets: Vite `publicDir` is the repo `assets/` folder; a build plugin deletes `dist/reference` so the 1024 px references never ship. Placeholder layers/strips are generated by `tools/gen_placeholders.py` and stamped PLACEHOLDER.
- Dev clock: `now() = Date.now() + settings.devClockOffsetMs`, persisted, so "fake the clock and relaunch" works for acceptance testing.
- Playwright drives the Vite build in a browser against `src/platform/browser.ts` (a mock of the Tauri boundary) because WebDriver for Tauri is not available on macOS; the real window is verified by hand and by the Rust-side integration.
